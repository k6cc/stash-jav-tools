# Peekaboo 插件使用说明

> v0.1.1：标签列表卡片（无封面）悬停也能露文字

把库里的封面、缩略图、播放器画面换成生成的抽象图案，不是高斯模糊。图片本身、数据库、文件一概不动，关掉即恢复。

## 安装

把 `peekaboo/` 复制到 Stash 插件目录（Windows `%USERPROFILE%\.stash\plugins\`，Docker `~/.stash/plugins/`），重载插件后在「设置 → 插件」能看到 Peekaboo 即成功。

开关三处等价：导航栏眼睛按钮（可用 Show navbar button 关掉）、`Shift+Alt+B`、设置页的 Shield on。状态存进库配置，换浏览器也保持。

## 兼容性

实测 Stash v0.31.0 与 v0.32.0：插件加载、图片与视频遮挡、文字打码、快捷键、设置项都正常。v0.32 起 UI 升到 React 18，插件只用公开的 `PluginApi`，不碰 React 内部结构，所以两个版本表现一致；v0.31.0 之前的版本未实测。

## 设置

| 设置项 | 默认 | 说明 |
|---|---|---|
| Shield on | OFF | 总开关 |
| Show navbar button | ON | OFF 时导航栏不出现眼睛按钮，只剩快捷键 |
| Reveal on hover | ON | 悬停片刻把整张卡片（含悬停才出现的预览视频）露出来，移开恢复；按住 Shift 则整页临时全露 |
| Reveal text as well | OFF | ON 时悬停或按住 Shift 连文字一起露出；OFF（默认）只露图片，标题、人名、标签保持遮罩 |
| Let videos keep playing | OFF | OFF 时播放器暂停且禁止播放；卡片预览不受影响（本就静音循环） |
| Keep text readable | OFF | OFF（默认）遮标题、简介、工作室/演员/标签名、别名、标签、详情值；ON 则完全不动文字。按钮、页签、筛选器始终可读 |
| Text mask style | sunny | 六种，见下表 |

| Text mask style | 效果 |
|---|---|
| `sunny` | 英文阳光词（Sunflower / Mint Soda）；项名一个词、主名 1–2 个、别名 3 个，其余按原文长度 |
| `symbol` | 灰色等长方块 |
| `black` | 纯黑等长方块 |
| `white` | 纯白等长方块 |
| `glyph` | 逐字符换成单色符号（✦ ✸ ❃ ※ § ¶ † ‡ ◈ ❖ ♪ ♫ ⌘ …），长度与原文一致 |
| `letters` | 逐字符换成字母，长度与原文一致 |

`sunny` 与 `letters` 的大小写跟 Stash 原生与 StashDB 的习惯一致：标题、人名、标签、字段值按单词首字母大写，简介类文字按句首大写。

设置页改完立即生效，不用刷新。

## 遮什么

| 对象 | 做法 |
|---|---|
| 图片、`<img>` 封面与剧照 | 按 URL 哈希取 32 种图案之一，同一张图在列表页、详情页、播放器里一致 |
| 视频画面 | 同上；播放器海报层、底部拖动预览条（雪碧图）、第三方插件的整片网格一并覆盖 |
| 文字 | 只换渲染出来的字；导航栏、页签、按钮、筛选器、表单、设置页不动 |
| 详情字段 | 场景/图库/图片的「工作室代码: ABF-363」这类行只换值，标签留着当路标；没有值的纯分组标题（「图库」「标签」）不动 |
| 泄漏点 | `title` 属性、`img alt`、浏览器标签页标题、复制出来的内容都只有替换后的字 |

图案是低饱和双色 + 同心圆/点阵/斜块/波纹四种母题，运行时生成，不占插件体积。

## 为什么不直接模糊

模糊保留构图、色调和轮廓，强度拉满仍能猜出画面。这里用 CSS 滤镜把元素输出整块换掉（滤镜只输出一张内嵌 SVG），原像素根本没参与绘制，所以不存在「糊得不够」的问题。

## 已知限制

- 原图仍会被浏览器下载，遮挡在渲染层；要连下载一起避免需在反代处理
- 用 `<canvas>` 自绘画面的插件盖不到
- 本浏览器从没打开过这个插件时，首屏按「开」处理，若库里设的是关会先遮一下再撤掉
