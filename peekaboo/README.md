# Peekaboo 插件使用说明

> v0.1.10：不再定时读取设置，设置页保存后换页或回到前台即生效

把库里的封面、缩略图、播放器画面换成生成的抽象图案，不是高斯模糊。图片本身、数据库、文件一概不动，关掉即恢复。

## 安装

把 `peekaboo/` 复制到 Stash 插件目录（Windows `%USERPROFILE%\.stash\plugins\`，Docker `~/.stash/plugins/`），重载插件。

## 兼容性

实测 Stash v0.31.0 与 v0.32.0，两者表现一致；更早的版本未实测。

## 快捷键

| 按键 | 作用 |
|---|---|
| `Shift+Alt+B` | 开关遮挡 |
| 按住 `Shift` | 整页临时露出原图 |

## 设置

| 设置项 | 默认 | 说明 |
|---|---|---|
| Shield on | OFF | 总开关 |
| Hide navbar button | OFF | ON 时导航栏不放眼睛按钮 |
| Reveal on hover | ON | 悬停卡片时临时露出原图 |
| Reveal text as well | OFF | 露出原图时连文字一起露 |
| Let videos keep playing | OFF | OFF 时视频停住；ON 照常播放，画面仍是图案 |
| Keep text readable | OFF | ON 时文字完全不动 |
| Text mask style | sunny | 六种，见下表 |

| Text mask style | 替换成 |
|---|---|
| `sunny` | 英文阳光词，如 Sunflower / Mint Soda |
| `symbol` | 灰色等长方块 |
| `black` | 纯黑等长方块 |
| `white` | 纯白等长方块 |
| `glyph` | 单色符号（✦ ✸ ❃ ※ § ¶ † ‡ ◈ ❖ ♪ ♫ ⌘ …） |
| `letters` | 字母 |

## 遮什么

| 对象 | 范围 |
|---|---|
| 封面与剧照 | 库里所有图片：场景封面、剧照、图库图片、演员与工作室头像 |
| 视频画面 | 播放器画面、海报、进度条预览，以及第三方插件铺满网格的视频 |
| 文字 | 标题、简介、工作室 / 演员 / 标签名、别名、标签、详情值；界面控件不动 |
| 详情字段 | 「工作室代码: ABF-363」这类行只换值，标签留着当路标 |
| 其他插件 | stashDiscover 的演员卡、演员与工作室详情、场景与演员弹窗、列表表格 |
| 属性与剪贴板 | `title`、`img alt`、浏览器标签页标题、复制出来的文字，都只有替换后的字 |

同一张图在库的任何位置都是同一个图案。

## 为什么不直接模糊

模糊保留构图、色调和轮廓，强度拉满仍能猜出画面。这里不是叠一层模糊，而是把元素要画的内容整块换掉，原像素根本没参与绘制，所以不存在「糊得不够」的问题。

## 已知限制

- 原图仍会被浏览器下载，遮挡在渲染层；要连下载一起避免需在反代处理
- 用 `<canvas>` 自绘画面的插件盖不到
