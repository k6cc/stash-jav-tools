# Studio Tools

> v1.5.3：工作室更新（搜索命中应用）改为只补不覆盖 — 主名不动，别名/链接仅去重并入缺失，上级工作室缺值不创建关联，Stash ID/图片仅补入不覆盖。

Stash 工作室详情页工具集 — 纯 UI 插件（JS + CSS，无需 Python）：**合并**重复工作室 + **多源搜索更新**工作室资料，两个模块共用同一注入入口。

## 依赖

| 项 | 说明 |
|---|---|
| Stash | v0.25+ |
| 浏览器 | Chrome / Firefox / Safari / Edge |
| Stash-box API Key | 仅 Search 模块需要（设置 → 元数据提供者 → Stash-box 端点，StashDB/ThePornDB/JAVStash 任一） |

## 安装

1. 将整个 `studioTools` 文件夹复制到 Stash 插件目录（`%USERPROFILE%\.stash\plugins\` 或 `~/.stash/plugins/`）
2. 重启 Stash（或设置 → 插件 → Reload plugins），工作室详情页出现「合并」「更新」按钮即成功

## 触发方式

| 入口 | 行为 |
|---|---|
| 详情页「合并」按钮 | 选择源（删除）/目标（保留）→ 逐字段对比 → 应用合并 |
| 详情页「更新」按钮 | 按名称搜索 Stash-box 实例 → 点击结果应用（只补不覆盖） |

## 核心机制

- **合并**：源/目标逐字段对比选择（主名、别名、链接、标签、图片、上级、Stash ID、评分、详情等）；正确执行顺序——先转移场景/图片/图库/组合/子工作室关联，再更新目标，最后删除源；非保留名自动追加为别名；Stash ID 多实例合并
- **更新（只补不覆盖）**：主名不动；别名/链接仅去重并入缺失；Stash ID/图片仅补入不覆盖；上级工作室缺值不创建关联（有值且本地已存在同名工作室才关联）
- **搜索**：内置 StashDB/ThePornDB/JAVStash + 元数据提供者中的自定义实例（按域名排序）；「全部」模式并发搜索（每源 8s 超时）；图片由 Stash 后端下载（Docker 兼容）

## 文件说明

| 文件 | 说明 |
|---|---|
| studioTools.yml | 插件定义 |
| studioTools.js | 合并 + 搜索更新逻辑 |
| studioTools.css | 模块样式 |

## 注意事项

- 合并会删除源工作室（引用已转移，数据不丢失），应用前确认影响范围
- 更新只补不覆盖：主名、已有图片与人工字段不会被改动
- Search 模块需先配置 Stash-box API Key
