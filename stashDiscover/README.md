# stashDiscover

> v2.7.6：修复加载失败后模块一直转圈、点「重试」无反应；工作室副标题不再显示「已收藏」。

在 Stash 演员页与工作室页插入「发现」分页，并提供主导航「发现」页：找出已配置 stash-box 实例上存在、本地库未拥有的场景。可浏览封面剧照与元数据、加入库、在 stash-box 查看，也可搜索资源并复制磁力或推送到下载器。

## 功能

- **演员页分页注入**：在演员详情页标签栏新增「发现」标签
- **多 stash-box 支持**：自动读取 Stash 配置的所有 stash-box 实例；端点写成 http:// 或带 www. 时按等价地址重试，内网实例不改写
- **无数据兜底面板**：未配置 stash-box / 演员无对应编号 / 源访问失败 / 源无结果时，按源列出状态与失败原因，面板内提供重试、打开编辑面板、在源上查看；源请求带 15 秒超时与错误分类，被限流（429）自动退避重试，部分源失败时卡片区顶部提示并可就地重试
- **编号关联闭环**：演员未关联编号时，可「在源上查找 TA」内联搜索各源同名演员并一键写入本地 stash_id；也可「打开编辑面板」拉起原生编辑覆盖层，写入编号后自动检测并重查
- **临时放宽时间窗口**：场景仅因时间窗口被过滤时，可「不限时间（本次）」临时放开近期/预告窗口（不写入设置），卡片区上方提供恢复入口
- **智能去重**：stash_id + 番号（code）双重匹配过滤本地已拥有场景；多 box 同场景按番号去重
- **近期窗口**（设置项 `recentDays`，默认 180）：仅显示最近 N 天内发行的场景，0 = 不限制。仅作用于演员/工作室 tab 的列表；发现页回看窗口独立，在发现页「设置」里调（默认 30 天）
- **预告窗口**（设置项 `previewDays`，默认 7，字符串输入以支持 "-1"）：未来发行的场景视为预告。-1 = 隐藏全部预告，0 = 不限制，N = 仅显示 N 天内的预告。仅作用于演员/工作室 tab 的列表；发现页不做未来窗口过滤，预告模块列全部未来场景。预告场景卡片左上角显示紫色「预告」角标
- **场景网格**：封面 + 标题 + 工作室 + 发行日期 + 时长 + 简介，与 Stash 原生 grid-card 一致；封面角标：时长右下、工作室右上、预告左上、来源左下（多源时）；文字下方显示演员/标签计数徽章，悬停弹出名单（本地演员带头像靠前）
- **场景列表**：原生 table-list 表格视图（封面、标题、日期、番号、时长、工作室、演员、标签），状态徽章（在库中 / 库内演员 / 已忽略）排在标题下一行、同一行左对齐；点击封面打开详情弹窗，点击标题新标签打开 stash-box 场景页
- **原生筛选条**：搜索（标题、番号、简介、工作室、演员、标签）、日期排序下拉、升降序切换、每页个数（默认 40，发现页内调整）、网格/列表显示切换（记忆选择）、卡片大小滑块（仅网格）；结果计数位于筛选条与卡片之间，底部分页为原生样式
- **详情弹窗**：
  - 封面 / 剧照轮播（左右翻页 + 计数器）；JAV 场景额外按番号 / r18 链接探测 DMM 官方剧照（欧美源仅有封面），打开时自动通过 `findScene` 获取完整详情（含导演、制作日期、URL 站点名等）
  - 主要操作按钮：加入库 / 在源站打开 / 找资源 / Whisparr / 忽略（后两颗只在对应配置或源支持时出现）
  - 完整元数据（标题、番号、发行/制作日期、时长、导演、工作室、演员、标签、简介、链接）；点击演员名在上方悬浮纯头像卡（左下角年龄、右下角国籍国旗），点击头像打开 stash-box 演员页，点击空白处关闭
- **加入库**：将 stash-box 场景元数据创建为本地场景（两段式确认防误操作）。自动按 stash_id 映射所有演员和工作室，查找/创建标签，stash_id 直接随创建提交；已在库的按下 stash_id + 番号判重跳过，按钮显示「在库中」。封面在入库落地后由后台串行补写，不占用等待时间，失败不影响其余字段
- **在 stash-box 查看**：新标签页打开该场景在对应 box 上的页面。已知源显示品牌名（javstash.org → JAVStash、stashdb.org → StashDB、theporndb.net → TPDB、fansdb.cc → FansDB），未知源回退显示主机名
- **Jackett 资源搜索**：通过 Jackett Torznab API 搜索（URL 只填根地址即可自动补全），带磁力的结果优先、按做种数排序，再按标题与搜索词的匹配度重排（匹配度低的折叠在列表末尾，点「显示」展开）；搜索词按场景自动推断——番号优先，无番号时用「YY MM DD + 首位女演员」，两者都没有才用标题，搜索框右侧标注当前用的是哪一种；结果为 0 时给「标题」按钮一键换词；每条结果标注来源索引器；点击搜索时弹窗自动滚动到底，结果返回后对齐结果抬头
- **复制磁力链接** / **推送下载**（qBittorrent、Motrix）/ **推送到 Whisparr**（仅 stashdb 源，仅支持 Whisparr v3）
- **双语界面** + **响应式设计**

## 发现页（主导航「发现」）

`enableDiscoverPage`（默认开启）是总闸，关掉后整个发现页模块不加载。日常收起入口不用关它 —— 导航按钮和内置菜单项一样，可以在 **设置 → 界面 → 菜单项目** 里勾选显示/隐藏（勾掉只隐藏按钮，直链 `/plugins/stashDiscover` 仍可打开）。

导航「发现」按钮聚合**库内演员**在 stash-box 上的未拥有新场景（回看窗口独立于演员 tab，在发现页「设置」里调整，默认 30 天，0 = 不限）：

- **总览 6 模块**：有新发布的演员（迷你卡）/ 最新发布（每人 cap 2）/ 热门（全站榜）/ 即将发布（预告）/ 工作室新发布（库内收藏工作室，cap 2/工作室）/ 发现演员（本地有更新 / 共同出演 / 热门演员榜，不在库的演员；前两者分页，每页随筛选栏 24 / 48 / 96）
- **钻取视图**：最新 / 热门 / 预告 / 工作室四个下钻页（面包屑 + 分页 + 搜索 + 排序 + 网格/列表切换）
- **热门不剔已入库**：热门榜保留完整榜单与名次，已入库的片在卡片左上角标「在库中」，列表模式标在标题下一行；其余视图仍只显示未拥有
- **热门演员榜补位**：已忽略与已在库的演员从榜上摘掉，由后面 30 名以内的人顶上；徽章沿用原始名次，不重新编号
- **演员过滤视图**：演员详情头部（头像/元数据/关注按钮/发现 Tab 跳转/主页/StashDB 外链）+ 该演员全部新场景
- **工作室过滤视图**：工作室分组 chip 条 → 工作室详情（场景列表，角标区分库内/未拥有）
- **数据源切换**：多源时工具栏可切换当前数据源（单源视角，与演员 tab 的多源合并互补）
- **主题跟随**：从当前页面采样派生设计 token，深色/浅色/自定义 CSS 主题自动适配；375px 窄屏适配
- **卡片复用**：与演员 tab 同一套场景卡（封面角标/悬停 popover/详情弹窗/加入库/Jackett），新场景带未读红框，点击即标记已读

### 批量选择

两个入口都能多选，场景与演员可混选后一次处理：

| 入口 | 可批量做的事 |
|---|---|
| 发现页工具栏的多选开关 | 忽略 / 加入库 |
| 演员页「发现」tab 的多选开关 | 忽略 / 加入库 |

批量入库走 `sceneCreate` 与 `batchAddPerformers`；已在库的条目跳过，结果按成功 / 失败 / 跳过分别回报。

### 入库字段

「加入库」写入哪些字段按场景 / 演员分别存默认值，也能在确认弹窗里当场改（当场改动不回写默认值）。演员是三态：全写 / 只关联库里已有的 / 不写 —— 「只关联」用来避免同名误建。

### 忽略记录（设置 → 已忽略管理）

发现页可忽略不想再看到的场景 / 演员；管理页按名字、别名、番号、工作室、演员名搜回，逐条或全部恢复。

演员页「发现」tab 里的场景被全部忽略后，面板会给出临时查看入口：放出来的卡片带「已忽略」角标，忽略记录不受影响，恢复隐藏即回到原来的列表。临时放出来的卡片再点「忽略」不会改写原记录（已有的直接跳过），批量撤销也只回滚本次新增的那些。

忽略时把卡片上现成的字段存成**快照**，管理页因此不发任何请求——已下架条目反查 stash-box 失败率高，且每次翻页都要等。

| 类型 | 字段 | 用途 |
|---|---|---|
| 场景 | `at` | 忽略时间：排序与弹窗「忽略于」 |
| 场景 | `title` `code` `studio` `date` | 卡片与弹窗文字、搜索命中 |
| 场景 | `cover` | 缩略图与弹窗封面 |
| 场景 | `p` | 前 4 位演员名：搜索 + 弹窗名单 |
| 场景 | `pn` | 演员总数，仅超过 4 位时写：卡片与弹窗显示 `+N` |
| 演员 | `at` `name` `image` | 排序 / 标题 / 头像 |
| 演员 | `alias_list` | 前 12 个别名：搜索 + 弹窗名单 |
| 演员 | `an` | 别名总数，仅超过 12 个时写：显示 `+N` |
| 演员 | `country` `birthdate` `gender` | 国旗、年龄（本地算）、性别符号 |

上限：场景 / 演员各 3000 条、整包 1,000,000 字符；超限按忽略时间淘汰最旧的，管理页显示累计淘汰条数。

**导出文件**（`stashDiscover-ignored-YYYY-MM-DD.json`）：

```json
{
  "version": 1,
  "exportedAt": "2026-10-30T12:00:00.000Z",
  "trimmed": 0,
  "scenes": {
    "<endpoint>:<sceneId>": { "at": 0, "title": "", "date": "", "code": "", "cover": "", "studio": "", "p": [] }
  },
  "performers": {
    "<endpoint>:<stashId>": { "at": 0, "name": "", "image": "", "alias_list": [], "country": "", "birthdate": "", "gender": "" }
  }
}
```

导入只补本地没有的键，不覆盖已有决策与忽略时间；`version` 比插件新的文件照读已知字段并提示；键不是 `endpoint:id`、或值不是对象的条目计入「格式无效」跳过。

## 关注通知系统

- **关注演员**：演员卡 ♥ / 演员弹层 / 演员过滤视图一键关注，新作品进「关注」视图分组展示
- **收藏导入**：「关注」视图与设置中可从库内收藏（❤）演员一键导入（仅导入有 stash-box 关联的）
- **未读提醒**：新场景红框 + 关注 tab 红点 + 导航「发现」按钮角标（未读数）；已读标记在回看窗口外才过期（窗口 + 7 天，窗口设为不限则不过期）
- **后台轮询**：打开 Stash 任意页面即检查关注演员新作品（每 6 小时至多一次，只查关注列表，轻量），角标随轮询结果更新，不必进发现页；发现页加载时再用全量管线对齐一次
- **免打扰**：设置中可关闭「关注的演员新发布提醒」（跳过轮询 + 隐藏角标）

## 工作室页「发现」tab

工作室详情页（`/studios/{id}`）注入与演员页同构的「发现」tab：该工作室（含 stash-box 层级匹配的母厂牌）在所有已配置 stash-box 的未拥有场景，多源合并，时间窗口与演员 tab 一致；「在源上查找」为演员专属功能，工作室 tab 不显示。

## 安装

1. 将 `stashDiscover/` 文件夹复制到 Stash 插件目录（`%USERPROFILE%\.stash\plugins\`）
2. 重启 Stash 或在 设置 → 插件 中 Reload Plugins
3. 确认插件已启用

### 依赖

- Stash v0.20+（推荐 v0.24+）
- Python 3.8+
- 已配置至少一个 stash-box 实例（设置 → 元数据提供者）
- 演员 / 工作室已关联对应 stash-box ID
- （可选）Jackett 实例、qBittorrent / Motrix、Whisparr

### Docker / Linux 部署

官方 `stashapp/stash` 镜像**不含 Python**，而 Jackett 搜索与推送到下载器这两条链路都要跑 `stashDiscover.py`。不装 Python 时这两项会报 `executable file not found`，其余功能（浏览、入库、关注）不受影响。

```dockerfile
FROM stashapp/stash:latest
USER root
RUN apk add --no-cache python3     # Debian 基础镜像用 apt-get install -y python3
USER stash
```

插件 `exec` 声明的是 `python`，Stash 会自己先找 `python3` 再找 `python`（也可在 Stash 设置里指定解释器路径），所以容器里装 `python3` 就够。

容器内填地址有两个坑：

| 场景 | 不要填 | 应该填 |
|---|---|---|
| Jackett 在宿主机 | `http://localhost:9117` | `http://<宿主局域网IP>:9117` 或 `http://host.docker.internal:9117` |
| qBittorrent 在宿主机 | `http://localhost:8080` | 同上 |

`localhost` / `127.0.0.1` 在容器里指向 Stash 容器自己，不是宿主机。Linux 上 `host.docker.internal` 需要 compose 里加 `extra_hosts: ["host.docker.internal:host-gateway"]`，或直接用宿主 IP。

插件目录挂载到 `/root/.stash/plugins/stashDiscover`；目录需可写（Python 要写 `__pycache__`）。反代超时见下方「注意事项」。

## 配置

在 设置 → 插件 → stashDiscover 中配置：

| 设置项 | 类型 | 默认 | 说明 |
|---|---|---|---|
| Recent Window (days) | STRING | 180 | 仅显示最近 N 天发行的场景。留空 = 180，0 = 不限制。仅演员/工作室 tab 生效，发现页的回看窗口在发现页「设置」里单独调（默认 30 天） |
| Preview Window (days) | STRING | 7 | 未来场景的预告窗口，字符串输入以支持 "-1"。-1 = 隐藏全部预告，0 = 不限制，N = N 天内。仅演员/工作室 tab 生效，发现页不过滤 |
| Jackett API URL | STRING | — | Jackett 根地址（自动补全 Torznab 端点）或完整 Torznab 端点，如 `http://127.0.0.1:9117` |
| Jackett API Key | STRING | — | Jackett API Key |
| Jackett Timeout (seconds) | STRING | 120 | Jackett 搜索超时秒数，留空 = 120，上限 600 |
| Downloader Type | STRING | qbittorrent | `qbittorrent` 或 `motrix`，留空 = qbittorrent |
| Downloader URL | STRING | — | qBittorrent Web UI 地址；Motrix 桌面版填 RPC 地址 `http://127.0.0.1:16800`，Docker 版填 Web 地址 |
| Downloader Username | STRING | — | qBittorrent 用户名，Motrix 留空 |
| Downloader Password | STRING | — | qBittorrent 密码；Motrix 填「高级 → RPC」里的密钥（桌面版）或 operator-token（Docker 版） |
| Whisparr URL | STRING | — | Whisparr v3 地址，如 `http://127.0.0.1:6969`。留空则不显示 Whisparr 按钮 |
| Whisparr API Key | STRING | — | Whisparr 设置 → 通用 → API Key |
| Preferred stash-box | STRING | — | 优先查询的 box 端点子串，留空=查询所有 |
| Discover page | BOOLEAN | true | 发现页总闸：关闭后导航入口消失、页面停用、discover.js 不加载，关注新作轮询与角标一并停用（演员/工作室页的「发现」tab 不受影响）；需刷新浏览器生效。只想收起导航按钮的话，去 设置 → 界面 → 菜单项目 里取消勾选「发现」即可 |

## 注意事项

- **资源搜索是同步请求**：结果由 Stash 的插件调用直接返回，不经日志。Jackett 慢时这个请求会一直挂着，最长到后端 `jackettTimeout`（默认 120 秒）。**反向代理若设 60 秒超时需放宽到 180 秒以上**，否则会被提前切断，界面看到的仍是失败。
- **源限流自动退避**：源返回 429 时按它要求的间隔重试，两次仍被拒才报错；被限流过的源随后五分钟内自动拉大请求间隔。超时、网络与鉴权错误不重试。
- 单次最多返回 200 条结果，超出时列表上方提示总数与实际显示条数，改搜索词可缩小范围。
- **搜索词质量决定结果质量**：Jackett 的查询是自由文本，索引器普遍按词匹配。插件按场景自动推断搜索词：番号（JAV）→ `YY MM DD 首位女演员`（欧美种子文件名就是这种格式，实测 12 条场景命中 9 条，按标题只有 3 条）→ 标题；演员名不是拉丁文的场景不拼日期词。泛匹配仍会带进无关条目，插件按命中率重排并折叠低匹配项，想更精确可直接改搜索框里的词。
- **qBittorrent 4.x / 5.x**：两者 Web UI API 兼容，实测 5.3.0 的推送下载正常。
- **Motrix 不用填保存目录**：桌面版走 aria2 的默认下载目录，Docker 版从 Motrix 自己的设置里读。密钥在 Motrix「高级 → RPC」里复制（桌面版），Docker 版是 `operator-token` 文件的内容。
- **Whisparr 只支持 v3**：走 `/api/v3`，v2 及更早的接口不兼容。按钮也只在 stashdb.org 源的场景出现 —— Whisparr 靠 stash_id 反查 TPDB 元数据，javstash 的 ID 它不认。质量档案在**发现页 → 设置 → 推送质量档案**里选；默认「自动」= 先找名字为 Any 的档案，再退到 id 最小的那个。根目录取 Whisparr 里的第一个。
- **封面在后台补写**：入库只等场景落地，封面另起一条串行队列去抓（单张最长 10 秒），所以点完「确认入库」立刻就能继续操作。队列没跑完就刷新页面，那几条封面会丢，场景本身不受影响；失败时会在队列排空后提示条数。
- **发现页数据缓存在浏览器**：12 小时内重进直接复用，右上角刷新强制重取。缓存超出浏览器配额时会裁掉较早条目，此时计数旁标注「缓存不完整」，点击即重新拉取。
- **更新插件后按 Ctrl+F5 强刷**：前端 JS/CSS 由 Stash 静态下发、不带版本号，浏览器会继续用旧的，界面看着像没更新。

## stash-box API 说明

本插件的 stash-box 调用约定：

- **场景列表**：`queryScenes(input:{performers:{value:[id],modifier:INCLUDES},sort:DATE,direction:DESC,page,per_page})`；工作室侧用 `studios:{value:[id],modifier:INCLUDES}`（stash-box 按层级匹配，含母厂牌）
- **场景图片**：`images[{url}]`（封面 + 剧照的扁平数组，非 front_cover/back_cover/screenshots）
- **场景详情**：`findScene(id)` 获取完整字段（director、production_date、urls.site 等）
- **Web 链接**：`new URL(endpoint).origin + "/scenes/" + id`
