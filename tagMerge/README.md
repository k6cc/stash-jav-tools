# tagMerge

> v2.5.0：映射表优先级链 — 导出生成自定义映射表（`tag_merge_map_<界面语言>.custom.json`），放入插件目录即优先加载，升级插件不覆盖

Stash 纯 UI 插件：读取映射库，把库内名称相似的 tags（英文/日文/中文变体）合并为规范中文 tag。源 tag 名称合并后保留为目标的别名，场景/标记/图库/图片上的引用由 Stash 后端统一转移，数据不丢失。映射表可在「查看映射」分页内查看、搜索、编辑并导出文件；导出生成**自定义映射表**（`tag_merge_map_<界面语言>.custom.json`），放入插件目录即优先加载，升级插件不覆盖。

## 依赖

- Stash v0.30+（`ui.assets` 资源路由，用于向面板提供 `tag_merge_map.json`）
- 无需 Python，无需 requests

## 安装

1. 将整个 `tagMerge` 文件夹复制到 Stash 插件目录（通常为 Stash 数据目录下的 `plugins/`）
2. 重启 Stash，在「设置 → 插件」中确认 Tag Merge 已启用

## 触发方式

| 入口 | 行为 |
|---|---|
| 导航栏绿色标签图标 | 面板：分组预览（逐组/全部合并） / 查看映射（编辑导出） / 日志 |

## 映射库格式

`tag_merge_map.json` 为纯 JSON，可手动编辑或在「查看映射」分页编辑后导出（面板经 `/plugin/tagMerge/assets/` 路由实时读取；每次扫描重新读取，替换文件后无需重启）。**映射表优先级**（前面的存在即用）：`tag_merge_map_<界面语言>.custom.json`（用户自定义，导出生成）→ `tag_merge_map.custom.json`（用户自定义）→ `tag_merge_map_<界面语言>.json`（发行版语言版，预留）→ `tag_merge_map.json`（发行版默认）。自定义文件随插件升级保留，发行版文件会被覆盖——浏览器端 JS 无法直接写服务器文件，编辑后「导出文件」下载的是自定义映射表（`tag_merge_map_<界面语言>.custom.json`，`<界面语言>` 取自当前界面语言），放入插件目录即优先加载：

```json
{
  "_说明": "以 _ 开头的键会被忽略",
  "3P/4P": ["3P·4P", "3P、4P", "3p", "4P", "4p", "３P"],
  "口枷": ["ボールギャグ", "口球", "球形口塞"]
}
```

- **键** = 合并目标 tag 名（目标不存在时执行中自动新建）；**值** = 源 tag 名列表（合并进目标并保留为别名），单行书写（「导出文件」即为单行格式，JSON 解析与换行无关，手动编辑时多行同样有效）
- 以 `_` 开头的键按值类型区分：**数组值 = 被忽略的映射**（扫描跳过，目标名去掉 `_` 前缀后可在面板「已忽略」筛选中一键恢复）；**字符串值 = 说明文字**（原样保留）
- 源名匹配为**归一化后精确匹配**：全角→半角（`３P`→`3P`）、不区分大小写、忽略全/半角空格及 `·、，/` 等分隔符；不做子串或模糊匹配

## 合并行为

调用 Stash 原生 `tagsMerge`（与官方「合并」对话框一致）：

1. 源 tag 的**场景/标记/图库/图片**等引用转移到目标（后端处理）
2. 源 tag 被删除，其名称由插件补写进目标的**别名**（幂等去重，仍可通过别名搜索）
3. 目标不存在时自动 `tagCreate` 新建（确认该组有有效源后才创建，避免产生空 tag）

## 安全机制

- **幂等**：已合并/不存在的源自动跳过，可安全重复执行；重新扫描即刷新预览
- **两级忽略**：可按源或按组忽略，均仅单次会话有效，不写入任何持久状态，重新扫描重置（不参与「合并全部」）
- **防链式**：某组的目标名不会成为其他组的源，避免 A→B、B→C 连环合并
- **编辑器重复校验**：查看映射分页实时检测归一化后的目标/源重复（红字提示 + 保存前确认），防止一个源名同时指向两个目标等配置错误
- **无删除操作**：只做合并，刮削器映射中的「删除」类关键词不在映射库中，插件完全不碰

## 文件说明

| 文件 | 说明 |
|---|---|
| `tagMerge.yml` | 插件定义（纯 UI 插件，assets 把插件目录挂载到 `/plugin/tagMerge/assets/`） |
| `tagMerge.js` | 面板逻辑：读映射库 → 扫描库内 tags → 分组预览 → 逐组/批量合并 + 补写别名 + 映射表编辑器 |
| `tagMerge.css` | 面板样式（tgm- 前缀，绿色主题） |
| `tag_merge_map.json` | 发行版映射数据库（初始版本，可在面板编辑或手动修改；升级插件会恢复为发行版） |
| `tag_merge_map*.custom.json` | 用户自定义映射表（导出生成，优先加载，升级插件不覆盖） |

## 注意事项

- 合并不可撤销（源 tag 删除，虽保留别名与引用），首次运行前请备份并预览 `tag_merge_map.json` 中将要生效的条目
- 映射库是静态文件，不随刮削器 `mapping_info.xml` 自动更新；如需刷新映射库请手动编辑或重新生成
- 分组卡片中的「未匹配 N 个源名」为正常现象：包括库内不存在的源名（映射库覆盖未来新增 tag）与已合并过的源
