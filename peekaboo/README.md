# Peekaboo 插件使用说明

> v0.1.0：首版。图片与视频画面替换成按 URL 生成的 SVG 图案，可选把标题、简介、人名、别名、标签一起遮掉；临时露原图有两种方式

把库里的封面、缩略图、播放器画面换成生成的抽象图案，不是高斯模糊。图片本身、数据库、文件一概不动，关掉即恢复。

## 安装

把 `peekaboo/` 复制到 Stash 插件目录（Windows `%USERPROFILE%\.stash\plugins\`，Docker `~/.stash/plugins/`），重载插件后在「设置 → 插件」能看到 Peekaboo 即成功。

开关三处等价：导航栏眼睛按钮、`Shift+Alt+B`、设置页的 Shield on。状态存进库配置，换浏览器也保持。

## 设置

| 设置项 | 默认 | 说明 |
|---|---|---|
| Shield on | OFF | 总开关 |
| Reveal on hover | ON | 悬停片刻把整张卡片（含悬停才出现的预览视频）露出来，移开恢复；按住 Shift 则整页临时全露 |
| Let videos keep playing | OFF | OFF 时播放器暂停且禁止播放；卡片预览不受影响（本就静音循环） |
| Mask text | ON | 遮标题、简介、工作室/演员/标签名、别名、标签、详情值；按钮、页签、筛选器不遮 |
| Text mask style | sunny | 五种，见下表 |

| Text mask style | 效果 |
|---|---|
| `sunny` | 英文阳光词（sunflower / mint）；项名一个词、主名 1–2 个、别名 3 个，其余按原文长度 |
| `symbol` | 灰色等长方块 |
| `black` | 纯黑等长方块 |
| `white` | 纯白等长方块 |
| `char` | 逐字符换成小写字母，长度与原文一致 |

设置页改完立即生效，不用刷新。

## 遮什么

| 对象 | 做法 |
|---|---|
| 图片、`<img>` 封面与剧照 | 按 URL 哈希取 32 种图案之一，同一张图在列表页、详情页、播放器里一致 |
| 视频画面 | 同上；播放器海报层、底部拖动预览条（雪碧图）、第三方插件的整片网格一并覆盖 |
| 文字 | 只换渲染出来的字；导航栏、页签、按钮、筛选器、表单、设置页不动 |
| 详情字段 | 场景/图库/图片的「工作室代码: ABF-363」这类行只换值，标签留着当路标；没有值的纯分组标题（「图库」「标签」）不动 |
| 泄漏点 | `title` 属性、`img alt`、浏览器标签页标题、复制出来的内容都只有替换后的字 |

图案是低饱和双色 + 同心圆/点阵/斜块/波纹四种母题，运行时生成，不占插件体积。

## 为什么不直接模糊

模糊保留构图、色调和轮廓，强度拉满仍能猜出画面。这里用 CSS 滤镜把元素输出整块换掉（滤镜只输出一张内嵌 SVG），原像素根本没参与绘制，所以不存在「糊得不够」的问题。

## 已知限制

- 原图仍会被浏览器下载，遮挡在渲染层；要连下载一起避免需在反代处理
- 用 `<canvas>` 自绘画面的插件盖不到
- 本浏览器从没打开过这个插件时，首屏按「开」处理，若库里设的是关会先遮一下再撤掉
